# Checker table

Every numbered feature, every field of his six Word forms and every line of his two handwritten pages, each mapped to a screen or marked "not possible offline". Kept by the Checker; nobody else edits it.

**How to read it**

- **ID.** `F-07a`: feature 7, first of the two places the scope names. `W`, `B`, `OR`, `OC`, `HR`, `HC`: worker form, building contract, organisation request, organisation contract, home request, home contract, numbered in form order. `BX-001`: the title of the complexes copy. `N1`, `N2`: the handwritten pages (N1 is the upright photo `…19.26.23(1).jpeg`, which reads first; N2 is the sideways one). Ids never change. One option is addressed as row plus index: `W-024.3`.
- **Source.** Where the text sits in the Word file: `T1.r2.c1 › T1.r2.c2` is table 1, row 2, label in cell 1, blank or options in cell 2. Cells are counted in file order, which is right to left on paper. `P2` is a paragraph, `P2.box` the text box anchored to it. The same ids are used in `docs/checker/forms/` and `docs/checker/data/`.
- **His text** is his wording with the stretching character removed and every blank written `……`. His spellings are kept. Print uses his raw strings, which are in the layout files.
- **Options or blank.** Options in his order, numbered `[1]`, `[2]`. A bare `……` is a dotted blank with no ☐. For a plain field it is the blank as he drew it (`…… دج`).
- **Maps to** uses the scope's screen names and the page folders of CLAUDE.md. Routes and field names are added from the code once it exists.
- **Screen** and **Print**: `not built`, `built`, `checked`, `mismatch`, or `n/a`. A row is `checked` only when the label and every option match in wording and order.
- **Notes** carry the ids of scope section 7 and 9 (H, P, F, R, A, and `scope N1` to `scope N3`, written that way so they are not taken for the handwritten blocks), question numbers (س) and the Checker's own findings (K), which are listed in `docs/checker/forms/differences.md`.
